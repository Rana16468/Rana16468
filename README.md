<a name="built"></a>
## 🚀 What I've Built

<details open>
<summary><b>🏢 Multi-Role Platform — Admin / User / Driver</b></summary>
<br/>

A logistics-style full-stack application featuring three distinct user roles with scoped dashboards and permission layers. Admins manage the platform; drivers update delivery states; users track real-time order status. Built with RBAC middleware and role-specific route guards.

**Stack:** `Next.js` · `Node.js` · `MongoDB` · `JWT` · `Tailwind CSS`

</details>

<details>
<summary><b>💳 Stripe Payment System with 80/20 Revenue Split</b></summary>
<br/>

Integrated Stripe with automatic revenue distribution — 80% to service providers, 20% to platform — on every successful transaction. Includes webhook event handling, refund flows, subscription support, and a full transaction history dashboard.

**Stack:** `Node.js` · `Stripe API` · `MongoDB` · `Express.js`

</details>

<details>
<summary><b>🤖 AI-Powered Data Validation System</b></summary>
<br/>

Built a pre-processing pipeline where user inputs are fed through an AI model for contextual and semantic validation before hitting the database. Reduces invalid submissions, improves data quality, and provides user-facing feedback in real time.

**Stack:** `Node.js` · `OpenAI API` · `Express.js` · `MongoDB`

</details>

<details>
<summary><b>🔍 Real-Time Filtering & Search Engine</b></summary>
<br/>

Designed a high-performance, query-builder-driven filtering system across large datasets with multi-field sorting, dynamic range filters, keyword search, and cursor-based pagination. Optimized with MongoDB indexes for fast response under load.

**Stack:** `Node.js` · `MongoDB` · `Mongoose` · `React`

</details>

<details>
<summary><b>🌍 Multi-Language Backend System</b></summary>
<br/>

Developed a locale-aware API middleware that dynamically translates response content based on user language preferences using the Google Translate API. Supports 30+ languages with caching to minimize API calls.

**Stack:** `Node.js` · `Google Translate API` · `Redis` · `Express.js`

</details>
